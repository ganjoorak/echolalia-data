# echolalia-data

آینهٔ فقط‌خواندنی از محتوای عمومی سایت اکولالیا که وب‌سایت [گنجورک](https://github.com/ganjoorak/website) از آن استفاده می‌کند.

## چرا کلون کردیم؟

گواهی TLS (سرتیفیکیت) سایت اکولالیا تمدید نشد (حدود ۲۸ مهر ۱۴۰۵ / ۱۹ اکتبر ۲۰۲۶ منقضی شد) و دریافت زندهٔ محتوا از آن‌جا غیرقابل‌اعتماد شد. به همین دلیل مجبور شدیم محتوا را کلون کنیم و از این آینه بخوانیم.

## حقوق

این محتوا با مجوز کد گنجورک (AGPL) بازنشر **نشده** است. همهٔ حقوق متن‌ها برای صاحبان اصلی‌شان محفوظ است.

## استفاده

```bash
git clone https://github.com/ganjoorak/echolalia-data.git data/echolalia
```

---

Read-only mirror of Echolalia's public content used by the ganjoorak website. We cloned it because Echolalia's TLS certificate was not renewed (expired around 2026-10-19), which made live fetches unreliable. Not relicensed: all rights stay with the original holders. Clone into `data/echolalia` of the website repo.
